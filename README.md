# Street Story

יישומון PWA נגיש בעברית לגילוי הסיפור שמאחורי שמות רחובות.

## פיילוט
הגרסה הראשונה מתמקדת בתל אביב-יפו.

## מטרות
- חיפוש לפי עיר + רחוב
- אימות שהרחוב קיים והצגת מיקומו
- מקור שם הרחוב
- שנת סלילה / ייסוד, כאשר קיים מקור אמין
- שנת מתן השם
- שמות קודמים ושינויי שם
- תיאור הרחוב ונקודות עניין
- הצגת מקורות לכל מידע היסטורי
- נגישות: ממשק RTL, ניגודיות גבוהה והקראה
- התקנה כ-PWA

## מצב נוכחי
החיפוש הגאוגרפי משתמש ב-OpenStreetMap Nominatim. נוספה שכבת מידע היסטורית מאומתת לפיילוט עבור חמישה רחובות מרכזיים בתל אביב-יפו: ביאליק, דיזנגוף, אלנבי, אבן גבירול ושדרות רוטשילד.

המידע ההיסטורי נשען בראש ובראשונה על מדריך הרחובות הרשמי ומקורות של עיריית תל אביב-יפו, ובמקרים מתאימים על מקורות משלימים כגון הספרייה הלאומית. מקורות מוצגים כקישורים בתוך תוצאת החיפוש.

כאשר שנת סלילה, שנת מתן השם או פרט אחר אינם מאומתים, היישומון מציג שהמידע לא נמצא במקום להשלים אותו בניחוש.

## קבצים עיקריים
- `index.html` — ממשק המשתמש
- `styles.css` — עיצוב ונגישות
- `app.js` — חיפוש, נתוני הפיילוט, תוצאות, מקורות והקראה
- `manifest.webmanifest` — הגדרות PWA
- `sw.js` — Service Worker ומטמון היישומון

## השלב הבא
להרחיב את מאגר הרחובות מעבר לחמשת רחובות הפיילוט, ובהמשך לעבור משכבת נתונים ידנית למנגנון נתונים מסודר שניתן לעדכן ולהרחיב בקלות.

## קרדיט למידע
מידע ממדריך הרחובות: באדיבות עיריית תל אביב-יפו.
