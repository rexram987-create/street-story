# Street Story

יישומון PWA נגיש בעברית לגילוי הסיפור שמאחורי שמות רחובות.

## פיילוט
הגרסה הראשונה מתמקדת בתל אביב-יפו.

## מטרות
- חיפוש לפי עיר + רחוב
- אימות שהרחוב קיים והצגת מיקומו
- מקור שם הרחוב
- שנת סלילה / ייסוד, כאשר קיים מקור אמין
- שנת מתן השם
- שמות קודמים ושינויי שם
- תיאור הרחוב ונקודות עניין
- הצגת מקורות לכל מידע היסטורי
- נגישות: ממשק RTL, ניגודיות גבוהה והקראה
- התקנה כ-PWA

## מצב נוכחי
השלד הראשוני קיים. החיפוש הגאוגרפי משתמש ב-OpenStreetMap Nominatim. המידע ההיסטורי עדיין אינו מוזן אוטומטית, ובכוונה מוצג כלא זמין עד לחיבור למקורות מוסמכים.

## קבצים עיקריים
- `index.html` — ממשק המשתמש
- `styles.css` — עיצוב ונגישות
- `app.js` — חיפוש, תוצאות והקראה
- `manifest.webmanifest` — הגדרות PWA
- `sw.js` — Service Worker בסיסי לשימוש במטמון

## השלב הבא
חיבור למקורות רשמיים של עיריית תל אביב-יפו ולמקורות משלימים כגון Wikidata/Wikipedia, תוך הפרדה ברורה בין שנת סלילה, שנת מתן השם ושמות קודמים.
